# Solis — Page-by-Page Visual & Interaction Blueprint

## 1. Daily Flow Dashboard (`/app/dashboard`)
* **Page Purpose**: The signature daily operating journey.
* **Primary Action**: Continue the next high-leverage intellectual action (Study, Focus, or Task).
* **Visual Anchor**: Time-aware Arrival statement & Manuscript Daily Intention line.
* **Content Hierarchy**:
  1. `01 // ARRIVAL & CONTINUITY`: Greeting, Intention line, Real Data Continuity Strip.
  2. `02 // SCULPTURAL MOMENTUM`: Large tabular numerical score (`84%`), calm copy, quad energy pillars.
  3. `03 // TODAY'S ASYMMETRIC STREAMS`: Left column (Study Horizon & Priority Intentions) vs. Right column (Subject Worlds, Knowledge Studio previews, Rituals).
  4. `04 // EVENING CLOSURE`: Reflection modal (*"What became clearer today?"* & *"What should tomorrow begin with?"*).
* **Responsive Art Direction**:
  - Desktop (`>1024px`): Asymmetric two-column stream layout.
  - Tablet (`768px - 1023px`): Single column vertical narrative with full-width cards.
  - Mobile (`<768px`): Linear touch-friendly scroll with bottom navigation.

---

## 2. Study Studio & Living Syllabus (`/app/study`)
* **Page Purpose**: Multi-discipline syllabus tracking and active learning roadmap.
* **Primary Action**: Launch Focus on a queued topic or add/manage syllabus topics.
* **Visual Anchor**: Subject World tiles with ambient discipline palette borders.
* **Content Hierarchy**:
  1. `01 // SUBJECT WORLDS`: Knowledge Disciplines with weekly target meters and thought counts.
  2. `02 // TODAY'S LIVING STUDY QUEUE`: Timeline-structured study items with 1-click Focus and Task conversion.
  3. `03 // TOPIC MASTERY PROGRESSION`: `unstudied` $\to$ `learning` $\to$ `mastered`.
  4. `04 // RECENT STUDY SYNTHESIS`: Clean session logs with retention ratings.

---

## 3. Focus Sanctuary (`/app/focus`)
* **Page Purpose**: Full-room distraction-free deep concentration environment.
* **Primary Action**: Start, Pause, or Complete the active focus block.
* **Visual Anchor**: Oversized tabular `Newsreader` countdown digits.
* **Content Hierarchy**:
  1. Header: Back link, Discipline chooser (with dynamic ambient orb color), acoustic bell test.
  2. Main: Intention manuscript line, giant countdown digits, Primary Play/Pause button, secondary reset.
  3. Post-Focus Canvas: Inline reflection prompt (*"What became clearer during this block?"*) with 1-click save to Knowledge Notes.

---

## 4. Knowledge Studio & Journal (`/app/notes`)
* **Page Purpose**: External memory, long-form synthesis, and conceptual capture.
* **Primary Action**: Distill and write a new insight or search the archive.
* **Visual Anchor**: Large `Newsreader` note title and reading canvas.
* **Content Hierarchy**:
  - Left Pane (Archive): Search, category segmented pills (`Concept`, `Lecture`, `Problem`, `Idea`), discipline filter, note list.
  - Right Pane (Canvas): Bounded reading line (`760px`), fluid 1.8 line-height, removable tag capsules, discrete auto-save indicator (`Auto-saved`).

---

## 5. Task Sanctuary (`/app/tasks`)
* **Page Purpose**: Intentional decision surface for intellectual tasks.
* **Primary Action**: Check off a priority task or add a new intention.
* **Visual Anchor**: Clean typographic task list ordered by priority and due date.
* **Content Hierarchy**:
  1. Time horizon `SegmentedControl` (`All`, `Today`, `Upcoming`).
  2. Search & Priority sort (`CustomSelect`).
  3. Task rows with subtask accordions.
